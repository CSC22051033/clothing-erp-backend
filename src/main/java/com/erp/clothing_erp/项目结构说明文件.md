# 项目结构说明文件

本项目采用经典的 **Spring Boot** 分层架构，主要包括以下四个核心模块：`entity`、`repository`、`service`、`controller`。各层职责清晰，便于维护与扩展。

## 目录结构

```
src/main/java/com/erp/clothing_erp
│
├── entity/ 				# 实体类
├── repository/ 			# 数据访问层
├── service/ 				# 业务逻辑层
├── controller/ 			# 控制器层
└── ClothingErpApplication.java 	# Spring Boot 启动类
```

## 各层说明

### 1. Entity 层（实体层）

* **作用**：与数据库表结构一一对应的 Java 对象，通常使用 JPA 注解进行映射。

### 2. Repository 层（数据访问层）

* **作用** ：封装对数据库的 CRUD 操作。通常继承 `JpaRepository` 或 `CrudRepository`，利用 Spring Data JPA 自动生成实现。

### 3. Service 层（业务逻辑层）

* **作用** ：处理核心业务逻辑，协调 Repository 进行数据操作，并可包含事务控制、权限校验等。

### 4. Controller 层（控制器层）

* **作用** ：接收 HTTP 请求，调用 Service 层方法，返回响应（JSON/XML）。使用 `@RestController` 和 `@RequestMapping` 等注解。
